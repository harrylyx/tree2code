# Domain Docs

This repository uses a single-context domain documentation layout.

## Before exploring

- Read the root `CONTEXT.md` for the project's canonical domain language.
- Read relevant decisions under `docs/adr/`.
- If a referenced document does not exist, continue without treating its absence as an error.

## Usage

Use the glossary's canonical terms in specifications, issues, tests, and implementation discussions. Surface any conflict with an existing architectural decision instead of silently overriding it.
