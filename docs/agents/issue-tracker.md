# Issue tracker: GitHub

Issues and specifications for this repository live as GitHub issues. Use the `gh` CLI for all operations and infer the repository from the configured Git remote.

## Conventions

- Create specifications and work requests as GitHub issues.
- Read issues with their comments and labels before acting on them.
- Apply and remove labels through GitHub.
- Close completed or rejected issues through GitHub.

## Pull requests as a triage surface

Pull requests are not treated as incoming requests for triage.

## Publishing

When an engineering skill says to publish to the issue tracker, create a GitHub issue in this repository.
